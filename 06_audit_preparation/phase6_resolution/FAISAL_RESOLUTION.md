# Faisal: Experimental Design Resolution (Phase 6)

All values are **PROVISIONALLY_SELECTED** in `CANDIDATE_EVALUATION_CONFIG.yaml`, with signoff `PENDING_HUMAN_SIGNOFF`. No real-data model was trained and no outer-test information was used.

| # | Decision | Candidate | Justification (existing evidence) | Remaining limitation |
| --- | --- | --- | --- | --- |
| B1 | Realization (F-D01) | noise-added primary; clean secondary; pooling forbidden | Labels identical across realizations; the publisher added noise to mimic sensors; one realization per run is enforced in code | The evidence does not show one is better; the choice is about realism |
| B2 | Grouped evaluation (F-D02/F-D03) | LOTO outer; LOTO-within-train inner | 0 leakage issues under 3 family views; deterministic folds; all classes in every train/test and inner split; nothing uses outer-test labels | Estimand = a held-out withdrawal topology of **this simulated network**; 3 folds |
| B3 | Windows (F-D04/F-D05) | 60 s / 30 s, `min_samples` 60, row-level labels, pre/post-event rows excluded; sensitivity 60 / 60 and `label_normal` | 1 s sampling verified; DELAY keeps 31 windows per run; boundary loss < 0.3%; excluding pre-event rows avoids time-in-run confounding | 60 s is a support compromise, not a physical derivation; overlapping windows are dependent (never inference units) |
| B4 | Features (F-D06) | 128 (16 channels × 8 statistics), scaling inside training folds; 80 offset-invariant as sensitivity | channels verified; no missing values; no cross-channel features (roles unverified) | absolute-level fingerprinting is tested only by the sensitivity arm |
| B5 | D(x) (F-D08) | k = 25 uniform, no prior correction, query-family exclusion, tie-inclusive; sensitivity k = 10 / 50 and prior correction | plan default; outer-train DELAY reference = 62 windows / 2 runs | **Implemented:** `TOP_CLASS_FEW_INDEPENDENT_RUNS` flag (`min_top_class_families = 2`), so a high D backed by a single run is flagged (tested) |
| B6 | Calibration (F-D09) | compare none vs sigmoid by log loss; isotonic excluded; **implemented** `calibration_feasibility` rule: if any class has fewer than 2 independent groups in development, fall back to "none" (reported) | In outer-train development each class appears in 2 topologies, so the rule permits sigmoid; isotonic would be fitted on single runs | calibration quality for thin classes rests on 2 runs |
| B7 | Policy (F-D11) | p-only candidates; singleton → UNRESOLVED; max set size 2; mass 0.9; OUT_OF_SUPPORT / INVALID / NO_REFERENCE → UNRESOLVED; LOW_SCENARIO_DIVERSITY and TOP_CLASS_FEW_INDEPENDENT_RUNS block SPECIFIC | weak or single-run evidence never becomes SPECIFIC | **Consequence (cross-owner):** in development folds NORMAL, FAULT and DELAY have one reference family, so SPECIFIC is reachable there only for LEAK. Report per-class realized coverage. Alternative for Faisal/Ahmed: record the flag without blocking |
| B8 | Thresholds (F-D12) | rank-matched target coverage 0.80 (primary), 0.60 / 0.90 secondary, chosen on development OOF only | **prespecified in the Faisal plan (F10 step 85)**, not chosen from data | if the held-out topology cannot reach the target, report realized coverage and flag it; never force it |
| B9 | Statistics (F-D13/F-D07) | paired family bootstrap stratified within topology, 2000 resamples, seed 20261104, pooled C vs C−D only, plus per-topology descriptive estimates; NORMAL / FAULT / DELAY descriptive | windows never resampled; topology strata preserved | intervals are **conditional on the 3 topologies**, not a generalisation interval; no significance claim for class-level effects |
| B10 | Missing components | **implemented and tested**: `combined_score.py` (cross-fitted s_C / s_{C−D}), `feature_table.py` (manifest → window/feature table; decisions as required arguments), `uncertainty.py` (stratified paired bootstrap) | `tests/test_phase6_components.py` | `feature_table.py` has not been run on the full real dataset (that would build the primary table before sign-off) |
| B11 | Candidate config (F-D17) | `CANDIDATE_EVALUATION_CONFIG.yaml`: no open values; every block PENDING_HUMAN_SIGNOFF; validated by `tests/test_candidate_config.py` | hashes match; objects constructible | not frozen |
