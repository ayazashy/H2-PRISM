# Prospective validation protocol proposal (candidate protocol 2.0)

- **Status:** PROPOSAL for owner decision. Nothing here is adopted, implemented or run.
- **Basis:** the forensic audit (`05_documentation/FORENSIC_FINDINGS_REPORT.md`, `06_audit_preparation/forensics/ROOT_CAUSE_REGISTER.csv`).
- **Protocol 1.1 and run R2 (`a10530f1fcf2`) remain the historical registered record and are never overwritten.**

## 0. Rules that apply to every candidate

1. Every choice below is fixed and approved **before** any new outer-test evaluation. No choice may be tuned on R2 or on any sensitivity run's held-out labels.
2. The R2 held-out results have already been seen. They can motivate a protocol, but they can **never** count as confirmation of it.
3. Confirmatory claims need evidence not used to design the protocol: new independent simulations, or a held-out partition fixed before any analysis.

## 2. What code cannot fix: new independent data

- NORMAL and DELAY have **one** scenario ancestor each, and FAULT has two (`independence_units.csv`). No support definition can make "≥ 2 independent ancestors" true for these classes.
- **Minimum request to the dataset owner/authors:** at least 3 independently parameterised scenarios per thin class (NORMAL, COMPRESSOR_FAULT, COMPRESSOR_DELAY) per topology. They should differ in operating parameters, not only in noise seed, and be generated by the topology's own model.
- A **fourth topology**, or an independent replicate network, is needed for any generalisation claim beyond the three simulated configurations.

## 3. Prospective validation design

1. **Freeze** P2-A … P2-H as accepted, write a new config (`protocol 2.0`) and pin its hash. Tie-break salt and coverage targets come from the P2-E pilot.
2. **Development pilot** (development data only):
   - attainability of each target in every inner split;
   - meta-model estimability;
   - share of pseudo-independent support (must be 0 under P2-C).
3. **Confirmatory evaluation:**
   - on new independent simulations (Section 2) if they are available;
   - otherwise on the corrected leave-one-topology-out design, with results labelled *not independent of the R2 inspection*.
4. **Single registered contrast:** s_C vs s_C−D at the pilot-fixed target, rank matched. Every other contrast is secondary and labelled as such.
